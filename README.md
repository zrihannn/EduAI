# EduAI Course Recommender

AI-powered free & paid course recommender platform for students, with NLP-driven notes extracting capabilities, an AI teacher, and curated content.

## Phase 1
Project scaffolding is complete:
- Spring Boot core directories & pom.xml
- React + Vite skeleton & package.json
- Python FastAPI microservice directories & requirements.txt
- Docker Compose setup

## Architecture
- **Backend**: Spring Boot 3 (Java 17)
- **Frontend**: React (Vite, Zustand, Tailwind)
- **AI Microservice**: Python FastAPI (KeyBERT, Transformers, GenAI SDKs)
- **Database**: PostgreSQL 15, Redis 7
