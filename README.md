# EduAI Course Recommender

An AI-assisted course discovery and learning platform for students. The project brings together free and paid course recommendations, notes extraction, an AI teacher experience, and curated learning content.

## Architecture

- **Backend:** Spring Boot with Java
- **Frontend:** React with Vite, Zustand, and Tailwind CSS
- **AI microservice:** Python FastAPI with KeyBERT, Transformers, and generative AI integrations
- **Database and caching:** PostgreSQL and Redis
- **Local development:** Docker Compose

## Project structure

The repository contains the core application scaffolding for the backend, frontend, AI service, database initialization, and local container orchestration.
